Glossary

102 terms an analyst hears in their first month, in plain English.

ABCDEFGHIKLMNOPRSTVW

A

A/B test
A randomised experiment comparing two variants, where randomisation makes the groups comparable so a difference in outcome can be attributed to the change. Read more →
ABC analysis
Classifying items (usually SKUs) by their share of total value, so planning effort concentrates on the ~20% that drive ~80% of value. Read more →
Accuracy
The share of predictions that are correct. Misleading whenever classes are imbalanced. Read more →
Adstock
The carryover effect of advertising, where spend in one period continues to influence sales in later periods. Read more →
ARIMA
A forecasting model combining autoregression, differencing for stationarity, and moving-average error terms. Read more →
ARPU
Average revenue per user, over a stated period. Read more →
Attribution
Assigning credit for a conversion across the marketing touchpoints that preceded it. A heuristic allocation, not a causal measurement. Read more →
AUC-PR
Area under the precision-recall curve. The preferred ranking metric when positives are rare. Read more →
AUC-ROC
Area under the ROC curve: the probability a random positive is ranked above a random negative. Read more →

B

Bagging
Training models on bootstrap samples and averaging them to reduce variance. The basis of random forests. Read more →
Base rate
The underlying prevalence of an outcome in the population. Ignoring it is the base rate fallacy. Read more →
Bayes' theorem
The rule for inverting a conditional probability: P(A|B) = P(B|A)P(A)/P(B). Read more →
Bootstrapping
Estimating uncertainty by repeatedly resampling the observed data with replacement. Read more →
Bullwhip effect
The amplification of demand variability as it moves upstream through a supply chain. Read more →

C

CAC
Customer acquisition cost: fully loaded acquisition spend divided by new customers acquired. Read more →
Calibration
Whether predicted probabilities match observed frequencies — among items scored 0.3, about 30% should be positive. Read more →
Cash conversion cycle
DIO + DSO − DPO: the days between paying suppliers and collecting from customers. Read more →
Central limit theorem
The result that the sampling distribution of the mean approaches normality as n grows, whatever the population's shape. Read more →
Churn rate
The share of customers lost during a period, measured against the count at the start of that period. Read more →
CLV / LTV
Customer lifetime value: the total gross profit a customer is expected to generate. Read more →
Cohort analysis
Grouping users by when they started and tracking each group separately, separating product quality from acquisition volume. Read more →
Confidence interval
A range built so that, over repeated sampling, a stated share of such intervals would contain the true parameter. Read more →
Confounder
A third variable that causes both of two correlated variables, creating an association that is not causal. Read more →
Contribution margin
Revenue minus variable costs — the amount each additional sale contributes toward fixed costs and profit. Read more →
Correlation
A measure of linear association between two variables, ranging from −1 to +1. Read more →
CRISP-DM
A six-phase analytics project lifecycle: business understanding, data understanding, preparation, modelling, evaluation, deployment. Read more →
Cross-validation
Repeatedly splitting data into train and validation folds to estimate out-of-sample performance more stably. Read more →

D

Data-ink ratio
Tufte's principle that the proportion of a chart's ink devoted to representing data should be maximised. Read more →
Descriptive analytics
Summarising what happened — counts, sums, rates and trends. Read more →
Diagnostic analytics
Determining why something happened, usually through disciplined segmentation. Read more →
Difference-in-differences
A quasi-experimental method comparing the before/after change in a treated group against an untreated control group. Read more →
Dimensionality
The number of features describing each observation. High dimensionality makes distance-based methods less reliable. Read more →

E

Elasticity
The percentage change in one quantity per percentage change in another; price elasticity of demand is the common case. Read more →
EOQ
Economic order quantity: the order size that minimises combined ordering and holding costs. Read more →
Expected value
The probability-weighted average of possible outcomes. Read more →

F

Fan-out
The row multiplication that occurs when joining on a key that is not unique, silently inflating aggregates. Read more →
Feature importance
A score for how much a model relies on each input. Predictive, never causal. Read more →
Fill rate
The share of ordered units shipped from available stock. Read more →
Funnel analysis
Measuring conversion through sequential stages to locate where users drop out. Read more →

G

Goodhart's Law
When a measure becomes a target, it ceases to be a good measure. Read more →
Gradient boosting
An ensemble method that builds trees sequentially, each fitting the errors of the ensemble so far. Read more →
Grain
What one row of a table or result represents. Most silent analytical errors are grain errors. Read more →
Gross margin
(Revenue − cost of goods sold) ÷ revenue. The fastest read on a business model. Read more →

H

Heteroscedasticity
Non-constant error variance in a regression, typically appearing as a funnel-shaped residual plot. Read more →
Hypothesis testing
A framework for judging whether observed data is plausible under a null hypothesis of no effect. Read more →

I

Imbalanced classes
A classification problem where one outcome is much rarer than the other, making accuracy misleading. Read more →
Incrementality
The causal effect of an activity, measured by comparing against a holdout that did not receive it. Read more →
Interval scale
A measurement scale with equal intervals but an arbitrary zero, so differences are meaningful and ratios are not. Read more →

K

K-means
A clustering algorithm that assigns points to the nearest of k centroids and iterates until assignments stabilise. Read more →
KPI
A metric a team has agreed to be measured against, as distinct from a metric that is merely tracked. Read more →

L

Leakage
Information in training data that would not be available at prediction time, producing inflated offline performance. Read more →
Log-normal
A right-skewed, strictly positive distribution whose logarithm is normal. The default shape of business data. Read more →
Logistic regression
A model of a binary outcome, linear in the log-odds and bounded between 0 and 1. Read more →

M

MAPE
Mean absolute percentage error. Scale-free but undefined near zero and biased toward under-forecasting. Read more →
MASE
Mean absolute scaled error: forecast MAE divided by naive MAE. Below 1 beats the naive baseline. Read more →
MDE
Minimum detectable effect: the smallest difference an experiment is designed to detect. Read more →
MECE
Mutually exclusive, collectively exhaustive — the property a good issue tree needs. Read more →
Median
The middle value of a sorted dataset; the robust measure of centre for skewed business data. Read more →
Multicollinearity
Strong correlation among predictors, which destabilises individual coefficients without harming prediction. Read more →

N

Nominal scale
Unordered categories, supporting counts and modes but no arithmetic. Read more →
NRR
Net revenue retention: revenue from an existing cohort versus its original revenue, including expansion. Above 100% means growth without new customers. Read more →
Null hypothesis
The default assumption of no effect or no difference, which a test attempts to reject. Read more →

O

Odds ratio
The exponentiated coefficient of a logistic regression — the multiplicative change in odds per unit of the predictor. Read more →
Ordinal scale
Ordered categories whose intervals are not known to be equal, supporting medians but not strictly means. Read more →
OTIF
On-time in-full: the share of orders delivered complete and on schedule. Read more →
Overfitting
Fitting noise in the training data, producing strong training performance and poor generalisation. Read more →

P

P-value
The probability of data at least as extreme as observed, assuming the null hypothesis is true. Read more →
Pareto principle
The empirical pattern that a small share of inputs accounts for most of the output — the 80/20 rule. Read more →
Peeking
Repeatedly checking an experiment and stopping when it reaches significance, which inflates the false positive rate. Read more →
Percentile
The value below which a given share of observations falls. p95 is often more decision-relevant than the mean. Read more →
Poisson distribution
The distribution of event counts in a fixed interval at a constant rate, where mean equals variance. Read more →
Power (statistical)
The probability of detecting an effect that genuinely exists; conventionally targeted at 80%. Read more →
Precision
Of the cases flagged positive, the share that really were positive. Read more →
Predictive analytics
Estimating unknown or future values from historical patterns. Read more →
Prescriptive analytics
Recommending an action, usually by combining a prediction with costs and constraints. Read more →
Pyramid principle
Structuring communication answer-first, with supporting arguments beneath it. Read more →

R

R-squared
The share of variance in the outcome explained by a regression model. Not a measure of correctness. Read more →
Random forest
An ensemble of decorrelated decision trees trained on bootstrap samples with random feature subsets. Read more →
Ratio scale
A scale with equal intervals and a true zero, so ratios and percentage changes are meaningful. Read more →
Recall
Of all genuine positives, the share the model successfully identified. Read more →
Regression to the mean
The tendency of extreme observations to be followed by more typical ones, often mistaken for the effect of an intervention. Read more →
RFM
Segmenting customers by recency, frequency and monetary value of their purchases. Read more →
ROAS
Return on ad spend: attributed revenue divided by advertising spend. Ignores margin. Read more →

S

Safety stock
Buffer inventory held to absorb variability in demand and lead time at a chosen service level. Read more →
Sampling bias
Systematic error from a sample that does not represent the population. No sample size fixes it. Read more →
Seasonality
Regular, fixed-period variation in a time series, such as weekly or annual cycles. Read more →
Segmentation
Dividing customers into groups that can be identified, are substantial, respond differently, and can be acted on. Read more →
Sensitivity analysis
Testing how much a conclusion changes when key assumptions are varied. Read more →
SHAP values
Per-prediction feature attributions with a game-theoretic basis, used to explain complex models. Read more →
Silhouette score
A measure of clustering quality comparing within-cluster to nearest-cluster distances. Read more →
Simpson's paradox
When a relationship present in every subgroup reverses once the groups are pooled, due to differing group mixes. Read more →
Skewness
Asymmetry in a distribution. Right skew, with mean above median, is the norm for business data. Read more →
SRM
Sample ratio mismatch: an experiment's traffic split differing from its intended allocation, indicating a defect. Read more →
Standard error
The standard deviation of a sample statistic's sampling distribution; for the mean it is σ/√n. Read more →
Stationarity
A time series whose statistical properties do not change over time — a requirement for ARIMA. Read more →
Survivorship bias
Drawing conclusions from surviving cases while the failures are absent from the data. Read more →

T

Type I error
Rejecting a true null hypothesis — a false positive. Read more →
Type II error
Failing to reject a false null hypothesis — a false negative. Read more →

V

Vanity metric
A number that rises regardless of performance and implies no action — typically a cumulative counter. Read more →
Variance analysis
Decomposing a gap against plan into price, volume and mix contributions. Read more →

W

Window function
A SQL function computing a value across related rows without collapsing them into one. Read more →
Working capital
Capital tied up in inventory and receivables, which consumes cash as a business grows. Read more →
